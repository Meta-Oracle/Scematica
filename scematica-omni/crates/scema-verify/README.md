# scema-verify

**Proof-carrying decision records.**

Part of [Scematica Omni](https://github.com/Meta-Oracle/Scematica/tree/main/scematica-omni) —
an agent runtime that perceives an environment, projects competing futures, ranks them under
a stated preference, decides *or refuses to*, and seals a verifiable record of what it did.

The organising idea across every crate: **each layer can say "I don't know", and saying it
costs nothing.** An agent that cannot express ignorance expresses a number of the right shape
instead, and nothing downstream can tell it from a measurement.

---

Canonical hashing and re-verification. Six SHA-256 digests — world, goal, hypotheses,
projections, policy, decision — and a root binding them to their field names.

**Read what this proves before quoting it at anyone.** It proves the record was not edited
after sealing, and names the field that moved. It does **not** prove the world was as
described — an observer that misread a repository produces a perfectly verifiable record of a
wrong observation, and provenance carries that. It does **not** prove the record is the
original: both a record and its commitment can be regenerated by whoever holds the file.
Tamper-evident, not tamper-proof, until the root is anchored somewhere the author does not
control.

**Floats are hashed as fixed-point.** A commitment over raw IEEE-754 bits is unverifiable the
moment a record crosses JSON, which is the only way one travels: `serde_json`'s formatter is
exact but its *parser* is not correctly rounded for every 17-digit input, so
`0.40066666666666667` returns one ULP low from its own identical text. Values are bound at
`1e-9` instead — an edit at or above that is caught, one below it cannot move any gate.
