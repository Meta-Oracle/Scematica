SCEMATICA OMNI — PAIRING

The extension talks to a scema-omnid running on this machine. Nothing is sent anywhere else, and the daemon binds to loopback only.

not tested

STARTING THE DAEMON

scema-omnid --allow /path/to/a/project
cat .scema/omnid.token

The token is generated once and reused, so pairing survives restarts. Delete the file to rotate it — every paired client will need the new one.

The token stays in this settings page and the extension's service worker. It is never given to the overlay running on a web page, so a hostile page that subverted the overlay still could not drive your agent.

Sealing records over HTTP is off unless the daemon was started with --allow-decide. That is the default because sealing a record is a local write, and a front end that can be driven by a page or a model should have to be told it may.

WHAT THIS TALKS TO

Only 127.0.0.1. That is the extension's entire host permission, and it is the reason the daemon can refuse CORS outright and still be usable — a service-worker fetch under host_permissions is not subject to it, while a web page is.

It does not talk to the Scematica website, and does not need to. The page you are browsing is the extension's input; your own daemon is what processes it.

The site's /omni page is a separate thing on the same project: an offline reader for records scema decide has already sealed. It shares no code path, no server and no network with this extension. It is also where an exported record should be checked — this extension deliberately recomputes no commitments of its own.

WHAT IT READS, AND WHEN

Nothing until you ask. There is no content_scripts block in the manifest and no <all_urls> permission. Perception happens through chrome.scripting.executeScript on the popup's button or the keyboard shortcut, under activeTab — one tab, one interaction.

It counts things: forms posting off-origin, third-party script origins, scripts with no integrity hash, mixed content, inline event handlers, unlabelled controls, heading-level skips. It never estimates a severity. That is what lets the simulator treat those magnitudes as measured — a "page quality score" invented in the browser would be a hallucination with a decimal point on it, laundered into a decision record.

The entity locator drops the query string and fragment before anything is sent. It is hashed into a record that outlives the tab, and query strings routinely carry session tokens.
