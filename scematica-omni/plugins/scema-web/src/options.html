SCEMATICA OMNI — PAIRING

The extension talks to a scema-omnid running on this machine. Nothing is sent anywhere else, and the daemon binds to loopback only.

not tested

STARTING THE DAEMON

scema-omnid --allow /path/to/a/project
cat .scema/omnid.token

The token is generated once and reused, so pairing survives restarts. Delete the file to rotate it — every paired client will need the new one.

The token stays in this settings page and the extension's service worker. It is never given to the overlay running on a web page, so a hostile page that subverted the overlay still could not drive your agent.
